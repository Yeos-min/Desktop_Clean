쓸어 담으세요.

바탕화면의 파일이 책상 위에 흩어진 물건처럼 놓입니다. 손으로 집어 폴더에 넣으세요. 설치 없이 체험할 수 있고, Desktop Helper를 연결하면 실제 폴더에 그대로 반영됩니다.

파일 준비 없이 먼저 체험해 보세요

준비된 가상 파일과 폴더로 정리를 체험합니다. 설치나 파일 접근 권한이 필요 없고, 실제 파일은 변경하지 않습니다.

설치 없음 · 확인창 없음

웹에서 바로 체험하기

바탕화면에서 CtrlA로 전부 고른 뒤 아래에 놓으세요. 파일은 읽기만 하고 디스크는 바꾸지 않습니다. 정리 결과는 계획으로 남습니다.

↓

바탕화면 항목 전부를 여기에 놓으세요.

파일은 카드가 되고 폴더는 배송지가 됩니다. 휴지통·내 PC 같은 항목은 자동으로 빠집니다. 폴더 안은 한 단계씩만 봅니다.

실제 반영

내 Desktop과 연결하기

작은 Desktop Helper를 실행하면 바탕화면을 자동으로 읽고, 옮기는 순간 실제 폴더에 반영됩니다. 되돌리기도 실제로 됩니다. Helper는 바탕화면 안의 이동과 새 폴더만 할 수 있고, 지우기는 없습니다.

  1. Desktop Helper를 받아 실행합니다. Node 20 이상이 있으면 node desktop-helper.mjs.
  2. 실행되면 브라우저가 이 페이지를 연결 주소로 엽니다. Chrome이 "로컬 네트워크 접근"을 물으면 허용하세요.
  3. 자동으로 안 열리면 Helper 창의 포트와 토큰을 넣고 연결하세요.

보드에는 한 번에 16장씩 올라오고, 나머지는 더미에서 이어서 나옵니다. 어떤 파일을 어디에 넣을지는 전부 당신이 정합니다. 자동 추천은 없습니다.

    조작

    화면을 클릭하면 마우스를 잡아 시점이 된다. Esc로 놓는다.

    • 마우스 · 둘러보기 (조준선이 곧 손이 닿는 곳)
    • WASD · 걷기. Shift로 빠르게
    • 카드를 보고 클릭 · 손에 담기. 누른 채 훑으면 닿는 대로 담긴다
    • 폴더를 보고 클릭 · 든 것을 전부 넣기. 빈손이면 폴더가 열린다
    • 샘플 상자 내부 · 클릭으로 선택, Shift+클릭으로 여러 개 선택, Esc로 들고 돌아오기
    • 1~9 · 든 것을 보이는 줄의 N번 폴더에 넣기
    • 오른쪽 버튼 · 겨누는 그 자리에 내려놓기
    • 더미를 보고 클릭 · 다음 무더기 꺼내기
    • CtrlA 전부 담기 · Backspace 칸 닫기
    • CtrlZ · 마지막 더미 되돌리기
    • Tab · 파일 정리 / 상자 배치 모드 전환
    • 상자 배치 · 좌클릭 집기/놓기, 휠로 15°씩 회전, 초록 미리보기에서만 놓기, 우클릭·Esc 취소
    • 배치 모드의 CtrlZ · 상자 위치 되돌리기. 설정은 ⚙ 버튼
